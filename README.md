# Шифровальщик Цезаря

caesar_cipher.py - это консольная програма реализующая классический шифр Цезаря с возможностью как зашфровки, так и расшифровки текста с изветсным ключом.

## Ключевые особености реализации
* **Мульитиязычность:** программа поддерживает `русский` (в том числе `ё`) и `английский` языки.
* **Регистрозависимость:** программа `сохранияет регистр` знаков, а символы неизвестных алфавитов или `знаки препинания остаются нетронутыми`.
* **Высокая призводительность:** `индексация алфавитов` при старте кратно ускоряет работу с текстом.

## Требования для запуска
* Установленный интарпретатор **`Python 3.6`** или выше.
* Стандартный модуль **`typing`** для python (чаще всего уже присутствует).

## Инструкция по запуску
1. Скопировать репозиторий и перейти в папку:
```bash
    git clone https://github.com/LynxDEV-0/caesar-cipher-zftsh.git
    cd caesar-cipher-zftsh
```
2. Запустить через терминал:
```bash
    python3 caesar-cipher.py
```
3. Для завершения работы программы использовать сочетание клавиш `Ctrl+C`.

## Примеры использования
Программа работает в бесконечном цикле последвательно принимая три значения от пользователя: `текст` -> `сдвиг/ключ` -> `режим`.
### 1. Зашифровка (`режим = 1`):
**Ввод в консоль:**
```text
Привет, мир! Hello, world!
3
1
```
**Вывод программы:**
```text
Тулезх, плу! Khoor, zruog!
```

### 2. Расшифровка (`режим = 2`)
**Ввод в консоль:**
```text
Тулезх, плу! Khoor, zruog!
3
2
```
**Вывод программы:**
```text
Привет, мир! Hello, world!
```
